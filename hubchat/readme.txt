ویجت چت آنلاین هاب‌چت را بدون ویرایش کد قالب روی سایت وردپرس نصب کنید.

== Description ==
پیام‌های بازدیدکنندگان سایت در صندوق مشترک هاب‌چت کنار تلگرام، بله، روبیکا و اینستاگرام می‌رسد.
ظاهر و امکانات ویجت (رنگ، آیکن، متن، پایگاه دانش، ساعات کاری و...) از پنل هاب‌چت تنظیم می‌شود.

== Installation ==
1. فایل zip افزونه را از «افزونه‌ها > افزودن > بارگذاری افزونه» نصب و فعال کنید.
2. به «تنظیمات > هاب‌چت» بروید و کلید ویجت (hc_...) را وارد کنید.
